Project 03 / Web Development + Backend

CamdenRoberts.com

A custom-built portfolio website with a TypeScript backend, developed to showcase my engineering projects while gaining practical experience with web development, API design, security, testing, and cloud deployment.

HTMLTypeScriptCloudflare PagesResendVitestAPI Integration

Overview

I began work on this project mid-November of 2026. I wanted a place to present my technical work, document my experience, and provide a direct way for prospective employers and collaborators to reach out and get in touch.

Rather than using a website builder or a prebuilt contact-form service, I decided to develop and deploy this site myself. This gave me an opportunity to work with technologies and development practices outside my previous projects and education while building something that I could actively use. Why use Squarespace when I have a perfectly good opportunity to learn how to make a site myself?

The website remains a work in progress, with a functional contact system and ongoing improvements to the content, interface, and performance. This project is somewhat of a test bed for my own discovery of web development.

Architecture

The frontend of this site uses HTML, CSS, and vanilla JavaScript. I chose to avoid a frontend framework to keep the site lightweight, to aid in my learning of web development, and to maintain direct control over the structure and behavior of the site throughout its lifespan.

This site is hosted on Cloudflare Pages and is deployed through a GitHub-connected workflow. The contact form communicates with a custom TypeScript API implemented using Cloudflare Pages Functions.

This architecture separates the static website from server-side request processing without requiring a traditional application server.

Contact API & Email Integration

I developed a contact API that accepts JSON submissions, validates all required fields, enforces input-length and request-size limits, and handles malformed requests.

The endpoint also performs strict UTF-8 decoding and normalizes accepted submissions before processing them.

To reduce automated submissions, the contact system integrates Cloudflare Turnstile with server-side token and hostname verification. A Cloudflare rate-limiting rule provides an additional layer of abuse protection.

Validated submissions are sent through the Resend email API using an authenticated address on my domain. Messages are delivered to my personal email address, with the sender's email configured as the Reply-To address.

Development & Testing

I implemented the frontend interactions, request-handling logic, API integrations, and deployment configuration, using AI assistance for technical guidance, code review, and test suite generation.

The backend is covered by 177 automated tests using Vitest. These exercise input validation, normalization, request-stream handling, Turnstile verification, email integration, and HTTP response behavior.

I also performed integration testing against a locally running Cloudflare environment and verified successful message delivery through the deployed website.

Challenges & Lessons

Several issues emerged during development, particularly around the differences between browser-side and server-side validation, asynchronous request handling, and handling failures without incorrectly reporting success to users.

Deploying the API also required configuring dependency installation for Cloudflare Pages Functions and securely managing environment variables.

Email integration introduced another set of practical challenges involving DNS configuration, sender authentication, DKIM, SPF, and DMARC. Working through these issues helped me better understand how application code interacts with the infrastructure supporting it.

Future Development

I plan to continue refining the website's visual design, mobile responsiveness, accessibility, and project documentation.

Further backend experimentation may include more advanced rate limiting, monitoring, and performance optimizations.

This project serves both as my professional portfolio and as an ongoing opportunity for me to develop practical software engineering skills.
